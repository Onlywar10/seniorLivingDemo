# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack
Next.js 16 (App Router, TypeScript, no Tailwind; global CSS with custom properties in `src/app/globals.css`, area CSS next to each page/component). Content in `src/data/`. Every page renders per request so dates are always current (America/Los_Angeles).

## Users
- Adult children shopping for care for a parent, often on a phone.
- Prospective residents (active older adults) comparing communities in Fairhollow / Rivermead / Calder.
- Current residents and families checking this week's calendar, menus and photos.
- Community staff (Events & Adventures, Fitness, Dining, Community Relations, Executive Director) using `/staff`.

## Product Purpose
An example website and staff publishing system for Wrenhaven Senior Living, a fictional operator, and its fictional communities Alder Bend and Kestrel Point. It behaves as if live: a calendar, menus, plans and pricing (all invented), kept current from one place and published everywhere (website, family texts, email digest, print).

## Brand Commitments
Alder Bend, "a Wrenhaven Senior Living Community". Palette: slate #415a68, brick red #bf4142, gold #d0c588, blue-grey #7591a1 and sage #a3b0a2 on cool sage-tinted grounds. Libre Baskerville headings, Montserrat text. Dot-crescent mark. Warm, upscale, active, joyful. No demo or sales copy inside the site chrome; the README states the content is fictional. Licence line (RCFE License #100000101) on every public page. Site stays noindex.

## Accessibility & Inclusion
WCAG 2.1 AA. 17px minimum body text, text-size and high-contrast controls, 44px targets, visible focus, English/Spanish, ASL interpreters available, LGBTQ+ inclusive care training.
